# DSH 工具与会话机制追加验证

记录日期：2026-10-21。本文件是本轮固定技术证据；批准、当前进度和后续工作只更新 [ROADMAP](ROADMAP.md)。实现依据 [ADR 0021](decisions/0021-dsh-tools-session-journal.md)，配置和日常操作见 [使用说明](dsh-tools-usage.md)，结构化结果见 [脱敏摘要](assets/dsh-tools-evidence.json)。

## 本轮交付

| 方面 | 实际结果 |
| --- | --- |
| 文件与项目工具 | 新增分页/行号 read、路径 glob、字面 grep、摘要绑定 edit；原 write、网页搜索/抓取及固定命令复用，项目命令非零退出码保留输出并记失败 |
| 授权与界面执行 | 新增配置目标 observe/act，Core/Node 策略摘要交集、首次目标范围确认、后续范围内连续执行；真实 Edge/Chrome 和受控测试程序已有证据 |
| 会话记录 | 每次聊天模型及 Search/Fetch 请求体在费用预留事务内保存，提交后才发送；原生调用、回复、流式部分和停止/中断单独保留；不存认证头或密钥 |
| 上下文与资料 | 保留近期完整问答，较早普通对话含来源摘录；容量按完整请求字节选择；同项目历史资料明确预览、逐轮外发同意和有效性复查 |
| 中途交互 | 纠正下一模型边界生效，未派发旧调用明确 not_started；后续消息有界排队、单条取消；已派发操作先收敛 |
| 恢复与记忆 | 原 attempt/回执先对账，recovery hold 阻止新派发；工具结果到下一模型交换之间也需明确继续；不自动保存个人记忆，不自动重发未知付费调用 |

本轮保持 Python/Core/Node 和现有执行器，没有新增运行依赖或第二套规划中心。schema 018 保留 grants 并扩大工具枚举，019 增加请求日志、控制、队列、来源与恢复字段；原历史和费用不重解释，升级前仍执行一致备份。

## 环境与固定包

本地 wheel：`var/dsh-tools/dist/nexus-0.1.0-py3-none-any.whl`，SHA-256 `b9f2b8e0d84b3e7f781295a4a53fe89235d74f42c5538b94650e5b7469ae8e8e`。139 个运行资源与最终源码逐字节一致，包含两份新迁移、Windows 固定操作脚本和新增网页脚本。固定包提取到独立目录后运行检查，没有安装或修改现有运行环境。它是本地候选包，不是生产发布。

## 中间失败及纠正

首轮全量为 821 passed / 4 failed / 2 skipped。发现并修复了重复重启导致会话 revision 反复增加的问题；另同步新增握手字段和迁移版本断言。旧流程重启夹具一次因测试进行时迁移资源仍在编辑而校验和不一致，日志确认后冻结资源复验，不修改迁移校验机制。相关 38 项复验通过，随后全量 830/2，通过最后恢复窗口修正后最终为上述 833/2。

真实交互测试先纠正了测试 Job 的关闭方式、测试控件的稳定 AutomationId、WPF 系统引用和浏览器初次加载等待。网页日志测试补充等待异步日志加载后再断言。默认沙箱临时目录的一次 wheel 构建遇到权限错误，改用工作区内专用构建临时目录成功；没有安装依赖、修改系统权限或绕过校验。

## 范围及剩余限制

- 现有未提交改动及同步文档清理保留；本轮没有删除用户文件、提交、推送或部署，也未配置日常浏览器或用户应用。本轮真实模型及 Search/Fetch 付费调用均为零。
- 浏览器仅专用 CDP 页面、明确 origin 和固定动作；应用仅已运行的明确路径/程序摘要/AutomationId，不等于通用桌面或任意浏览器控制。观察摘要覆盖有限界面，无法提供跨应用事务锁。
- 取消停止真实交换、后续派发和 Node 操作桥；已发出的点击、导航或应用业务效果不能回滚。动作返回不等于业务成功，未知执行不能推断未发生。
- 新工具须同时配置 Core/Node 和持久授权；升级不自动授权，先 Core 后 Node。旧版本缺失的逐次请求不可追溯补造。grep 首批是字面匹配，不是完整 DSH 正则实现。
- 保持原 4 动作/5 模型交换、20 底层操作及费用限制。跨会话资料仅同项目/owner、显式选定且有界，不递归引用；长期记忆仍需单独同意。
- 这版尚未在生产或 Linux Core 上部署验证，未测试用户真实程序、实际 Search/Fetch 供应商、Android 真机或新的真实 runsc 组合；技术自检不代替最终用户验收，也不进入 M7/M8。
