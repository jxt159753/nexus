# M6 工作区默认权限、工具交换修复与网页工具验证

记录日期：2026-10-20。当前批准与阶段状态只更新 [ROADMAP](ROADMAP.md)，设计见 [ADR 0019](decisions/0019-workspace-defaults-web-tools.md)，脱敏数据见[证据 JSON](assets/m6-work-fix-evidence.json)。此前 schema 016 发布保留在[原记录](M6-WORK-VERIFICATION.md)。

## 实际变更

- 配置好的 workspace 文件读写与查找默认执行，无额外会话授权和写入答复；真实预览、旧内容摘要、路径保护和读回验证保留。旧待确认写入不自动批准。
- 原生函数按 index 收集，兼容交错参数和后续空名称/类型。整批校验后按顺序执行，结果收齐才继续；仍每轮 4 动作/5 次模型交换。
- 稳定模型错误保留，有效完整用量已知的失败可结算；无用量及历史未知预留保留。旧报告的首次交换失败前没有设备任务，权限有效；未保存原始响应，不能证明历史一定因多调用失败。
- `web_search` / `web_fetch` 接入 DeepSeek 独立 API，参考官方 DSH Provider/Transport 源码。固定端点、10 秒/256 KiB 限制、最多 5 项来源/8 KiB 正文、预算及账本先落盘，停止关闭真实交换，不重试未知请求。来源链接和截断可在工作记录查看。
- 超长网页上下文导致停止时仍保存已知费用，不让聊天工作协程退出。
