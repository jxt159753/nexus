# ADR 0048：Core 持续任务与独立设备提醒通道

- 日期：2026-10-25
- 范围：本轮通用定时、长期任务和跨设备提醒，含前端；上线状态只见 ROADMAP。

## 决定

扩展现有 Core 调度与 goal 状态，不新增消息中间件或 Node 规划器。用显式标志表达“无结束日期”，保留旧有限任务字段及数据；仍检查真实授权、用户停止、执行结算与机器验收。持续工作复用稳定 wakeup/request ID，错过周期只补一次，取消未提交事件不会在恢复后重放。

Core 同一事务保存提醒内容和各接收目标；独立接收令牌只可读取本设备待投递记录、确认系统通知提交。owner 会话负责登记、撤销、已读与任务控制。提醒发送、系统提交回执和用户已读分开记录，绝不将回执标记为用户验收。

用户手机为红魔且 Google Play 不确定，采用用户主动开启的 Android 前台连接服务、系统通知、有限续期唤醒锁和省电设置引导；Windows 复用原生托盘进程与 WinRT Toast。没有加入推送供应商或第三方依赖。原生端持久去重，断网补收，关闭通知时不确认成功投递。

## 取舍

Android 无厂商或 Google 推送通道时，长期及时提醒需要常驻服务和用户允许后台运行，耗电高于系统推送。不能承诺绕过强行停止、厂商进程清理或关机；真机验收单独保留。浏览器页面提供统一控制和历史，不以页面计时器冒充后台系统推送。

持续运行不等于无条件继续。来源同意被撤销、权限／工具版本改变、未知执行、缺乏进展或真实存储不足仍停止新执行。用户设定的次数／期限属于任务语义，不重新引入累计模型调用或金额额度。
