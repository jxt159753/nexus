# ADR 0036：失败后的自然语言反馈与网页读取继续

日期：2026-10-23。状态：已采纳；本地实现与验证、部署和用户验收分别记 [ROADMAP](../ROADMAP.md#p76错误自然语言反馈)。

用户报告搜索校园图片时，搜索成功后网页抓取超时，整轮只留下 `WEB_TIMEOUT`、费用预留和技术 JSON；随后明确要求所有此类错误最终交给 LLM 解释，并授权 Codex 直接修改本次前后端。

代码根因是网页请求结束和费用是否确定被合并判断：费用未知便中止整轮，已有搜索结果不能进入下一次模型交换。同时展示层仅在完成态提供最终回答，失败后的部分文本仍标作“正在生成”。

## 决定

1. 区分只读网页请求的交换结束、工具成功和费用已知。超时、断流或无效响应由 Provider 返回后，保存失败结果并送回原工具循环；同批其他动作及模型可在原限制内继续。费用未知保留完整预留并计入余额，不能记为零或宣称已退款。主动取消和重启遗留请求仍是未知，不重发。
2. 不增加传输重试。相同根轮次中，已结束但费用未知的相同网页请求被拒绝且记录未发送；模型可以使用已有资料、不同来源或直接总结。保留 4 动作、5 次模型交换、每日次数、时限、外发与权限检查。
3. 普通工具、预览和参数错误沿用原生工具结果反馈。使整轮终止的错误，在原授权有效、调用已结算、子执行已停止、上下文和剩余预算允许时，最多增加一次仅解释的模型交换，计入原 5 次上限。该阶段不提供工具，不处理新的工具建议或自动修正，不扩张计划。
4. 解释使用原轮次已同意的上下文和有界结果摘录；原始错误和执行事实保留。模型回答完成只代表解释结束，不将失败或未知执行改成成功。用户停止/拒绝/撤权、暂停、到期、有后续轮次、恢复未决或模型本身无法安全再调用时，不追加解释调用。
5. 所有失败、停止、未完整结束、中断和恢复记录均可由展示层生成自然语言兜底；已有来源最多保留 5 项，不能把搜索摘要说成已取得页面或图片。读取历史不触发模型或执行。旧手动回传入口保留原同意边界，缺少同意时只展示兜底。
6. 前端将最终回答或本轮反馈放在处理过程之前，失败过程保持展开，错误码与原始 JSON 放在技术详情。`live_text` 只有正在回复时标作生成中，停止后标作已保留片段。Web、Windows 随包页面和旧控制台保持一致。

不新增依赖、迁移、Node 能力或后台恢复调度。不能保证模型/网络永远可用，也不以“必须有 LLM 解释”为由无限重试。此前文档中的未知费用阻止继续，针对已结束只读网页请求由本决定替代；未知模型用量、未停止执行及恢复边界保持。
