# ADR 0016：聊天选择固定流程与执行记录衔接

日期：2026-10-19。用户明确要求“完成 M5”，授权 P25–P28 的本地实现与验证。2026-10-20 用户另行明确批准将固定包 `42f51704…663592a` 部署到既有单活云端 Core，先一致备份并保留身份、历史、权限和预算；不含真实模型外发或 GitHub 推送。M4 原有未验收项不因此自动通过；生产发布、真实模型外发和 Android 真机验收分别记录。

## 决定

1. 保留现有聊天、SkillService、Harness 和共享账本。模型最多建议一个已测试、逐版批准且已启用的流程；不生成计划代码，不启用新版本，不另建执行状态机。
2. 流程建议默认关闭。发送前展示本轮可外发的有限能力目录，用户逐次允许发送；目录摘要在提交时重查，保存实际快照。目录不含设备身份、宿主路径、源码、秘密或旧执行结果。
3. 建议后显示固定版本、摘要、输入格式、最多三个步骤、设备、数据范围和审批点。缺参数时由用户补齐后重新预览。计划摘要绑定输入、版本、依赖批准、节点范围、策略与到期时间；旧摘要不能确认新参数或新版本。
4. 确认与 Skill 运行及会话关联同事务提交，重复确认返回同一运行。后续执行完全复用已有流程；目录动作单独审批。停止模型回复、取消流程、暂停新派发分别操作。
5. 会话查询已有运行与每步任务，刷新、断线、重启不重新创建或执行。失败、取消、超时和结果未知保留在执行卡中；模型文字不改变实际状态。
6. 成功后可选择步骤并预览白名单结果，再逐次同意解读。沿用同轮第二次调用及 USD 0.05 总上限；首次费用未知、策略变化、后续会话消息或结果变化阻止外发。流程首版不提供执行前自动回传，避免将不确定输出范围当成已预览内容。

## 完成边界

本地回归、真实 Windows 独立进程、浏览器与 Android 真机、Linux/runsc、真实模型、生产部署及用户验收分别列证据。M5 不承担或掩盖 M4 缺口；没有所需已启用流程时明确提示缺少能力，不临时执行新代码。
