# ADR 0001：S2 权威事务、随机凭证与动作审批

日期：2026-10-17。状态：按用户“完成 S2”授权实施；技术交付不代替用户验收。沿用 [ARCHITECTURE](../ARCHITECTURE.md) 的设计边界，不扩展到设备执行。

SQLite 使用 aiosqlite 与版本 SQL，不引入 ORM。每个短事务使用独立连接，写入由 BEGIN IMMEDIATE 串行化；任务、revision、事件和审计一次提交，避免共享连接上多个协程混入同一事务。已有数据库升级先一致备份并检查，未知版本或无版本旧库显式拒绝。

身份采用独立高熵随机令牌，Core 只存摘要；owner 换取限时会话，Node 保持独立 Bearer 身份。管理命令仅离线可用，秘密从环境进入且不输出。离线动作与认证动作在审计中区分操作者和被管理对象。

权限采用固定工具与资源白名单；Node 自报能力只能缩小已配置权限。审批绑定不可变任务动作、身份、节点、策略/资源范围和期限。每次操作重查撤销状态；审批检查与任务更新使用同一事务。目录操作经审批验证机制，MVP 不引入副作用工具。

代价：独立连接有少量线程/连接开销；全局策略版本变化会保守地使既有目录审批失效。当前单用户、小队列规模优先采用简单、可验证的实现。后续 P06/P07 必须在真实连接与派发事务中重新检查权限，单活进程锁、attempt、真实结果和恢复由相应后续任务完成。
