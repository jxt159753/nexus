# ADR 0009：单 Provider、费用预留与先确认的自然语言任务

日期：2026-10-18。依据：用户确认 M1 验收完成，并明确选择 M2 真实模型/自然语言、DeepSeek，以及每天 USD 1、每任务 USD 0.05。实施与验证状态统一见 [ROADMAP](../ROADMAP.md#8-m2真实模型与受约束自然语言任务)。

M1 的任务必须已有严格动作和授权，模型占位接口及旧 model_calls 不支持解释阶段预算。直接让模型创建工具命令会混淆建议、授权和执行事实；直接把自然语言塞进既有 ToolCall 又会破坏已验收的 Node 边界。

决定：增加 Core 内部有限的解释前置流程，复用既有 Provider 边界、Core SQLite 事务、原 Harness、两个工具与浏览器会话。语言请求先入库，模型只返回有限动作建议，用户确认后由原授权链处理。确认创建任务和关联语言记录同事务提交；仍只有 Harness 决定任务状态。

首个适配器只访问 DeepSeek 官方 HTTPS Chat API，使用当前 deepseek-flash、JSON 输出及非思考模式。不接入 SDK、服务端搜索或模型工具调用；将已锁定的 httpx2 从开发依赖转为运行依赖，无新版本。Key 只在 Core 环境变量中，默认禁用且每次外发需明确同意。只发送本次输入及静态允许动作说明。

费用上限以整数记录，调用前原子预留单项最大费用并计入每日总额和调用次数。返回用量按有效公开峰值快照计算上界，失败且费用未知时保留完整预留；跨日和重启不释放未知成本，不自动重试。价格快照过期停止新调用。模型响应无效时仍结算已有用量。

迁移 006 沿用升级前一致备份。model_calls 的 task_id 可为空以容纳确认前的真实调用，新增语言请求、预算及用量字段；通过新表/完整复制保留旧七列及全部行，不改已有迁移摘要。language_requests 是有界输入与解释历史，不是第二个任务权威或自动个人记忆。

暂停与启动按同一操作锁排序；取消会终止实际 HTTP 等待并保留未知成本，不能撤销供应商已开始的工作。恢复不重发不确定的模型调用。模型解释校验通过不等于工具完成，最终成功仍由 Node 证据和原验证器决定。

代价：单并发、每次确认和保守费用预留牺牲部分吞吐；未知费用需人工核对，当前不自动释放。M2 不提供通用聊天、多步骤规划、自动记忆、写操作、新设备工具或 Android 原生 Node。后续扩展须基于具体目标重新设计和批准。

依据：[官方模型/定价](https://api-docs.deepseek.com/quick_start/pricing/)、[JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)、[Chat API](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)。核对日 2026-10-18；价格和模型别名不能视为永久不变。
