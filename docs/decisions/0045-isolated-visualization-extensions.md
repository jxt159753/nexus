# ADR 0045：由 Core 管理的隔离可视化插件闭环

日期：2026-10-24。范围：用户已批准的自主插件开发、构建、验证、升级和失败回退；网页/Windows 前端及本地 MediaPipe 依赖由 Codex 一并实现。

## 决定

复用现有聊天工作循环作为唯一开发循环。新增 `inspect_ui_extension` 和 `submit_ui_extension`，Core 保存固定候选、策略、租约、独立输出证据及版本指针；现有 Python 插件、Node 和权限系统保持各自职责。

可视化插件使用固定 `visualization-worker-v1` 数据契约。Core 构建规范 JSON 包；浏览器加载到无同源权限的 iframe Worker。候选只接收归一化手部数据，返回四种严格场景指令，不能进入带凭据的主页面执行域。MediaPipe 是可信客户端组件，随包分发并在独立线程本地识别，摄像头需用户主动开启。

发布依据宿主用例的实际输出和运行准备回执，采用策略修订、基线版本、包摘要及租约约束。失败保留旧版或按当前部署修订回退；禁止迟到回执覆盖新版本，不回退业务数据库或授权。owner 的显式会话策略允许限定能力内后续版本自动升级，模型不能设置策略。

## 原因与代价

把生成 JavaScript 直接导入登录页面会暴露登录状态和 Windows 原生桥；把浏览器 SDK 塞进 Python 插件不能验证实际页面接入。固定数据接口让插件开发和升级无需修改主程序，也能在每一版使用真实浏览器隔离执行和复用 Three.js 场景。

构建使用确定性封装，没有候选 npm 脚本、任意依赖安装或 Core 导入。代价是当前只能实现约定的手势场景控制；新增宿主能力必须作为独立代码变更评审。固定用例、实际运行证据与真人体验分开记录，不能仅靠通过有限用例宣称手势识别体验已验收。

Worker 的超时终止不等于操作系统沙箱资源限制；不把本方案推广为任意不可信宿主代码执行器。[ADR 0035](0035-scoped-self-iteration.md) 的完整源码构建/发布器不由本次可视化插件运行时替代。协议与使用见 [ui-extensions.md](../ui-extensions.md)，状态见 [P90](../ROADMAP.md#p90-extension-evolution)。
