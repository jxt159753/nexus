# ADR 0050：本机权限选择自动同步 Core

日期：2026-10-26。状态：按用户明确要求实施并部署；验证及验收状态见 [P107](../ROADMAP.md#p107-device-permissions)。

## 问题与决定

Android 已有本机开关和 Core 静态授权，用户需重复开启。复用现有 owner 会话与安装证明，把用户保存的本机选择同步到 Core。Node 令牌和能力上报仍不能授予权限；模型不参与授权转换。

Core 按安装实例保存单调版本及完整已知选择快照，并与策略、设备范围授权和审计事务提交。仅改变的选择更新授权；重复请求只读回，不覆盖随后通过其他客户端做出的撤销。迁移只新增表，不回填或增加授权。客户端先落盘再提交，恢复后核对确认；失败不阻塞聊天，关闭本机开关立即约束执行。

注册后的功能询问由 Core 的确定性管理响应生成。常见注册、改名、权限表达仍要求完整明确；简短功能列表只接受同一会话上一条注册问题及相同安装证明。不把模型推测、引用、问句或“全部”当作授权。

## 影响与边界

- 设备身份、系统授权、用户所选目录、normal／full 审批和执行回执保持原边界。
- 新版 Android 会同步已保存的本机选择；已有 Core 撤销不会被重复旧快照恢复。再次改变该项本机选择才会重新更新它。
- 初次未明确选择的收件箱权限由 Core 注册选择控制，默认能力声明不构成授权；本机系统服务和目录依然由用户操作。
- 只覆盖当前 Android 本机开关，不把 Windows 配置、任意工具名或 Node 自报能力自动提升为 owner 权限。
- 客户端需登录且前台同步，离线／后台期间保留选择；旧 Core 返回不支持时明确提示升级。旧客户端保留原接口。
