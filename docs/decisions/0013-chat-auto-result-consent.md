# ADR 0013：工具确认时同意结果自动回传

日期：2026-10-19。状态：已批准并上线，真实自动回传与连续追问技术验证通过、待用户验收；部署记录见 [ROADMAP](../ROADMAP.md#13-m3-补充确认工具时同意自动回传)。

用户实际操作暴露了 ADR 0012 的流程缺口：工具已成功，但用户直接追问时，模型只有旧建议文字，结果尚未外发；旧轮次又因已有后续消息失去续接资格。用户明确选择“采用这个流程，勾选后自动回传”，允许在执行前对本次有限结果范围同意外发。

确认卡增加默认未勾选的“允许本次白名单结果回传 DeepSeek，成功后自动回答”。系统工具仅四项系统字段；目录仅 workspace 别名、直接条目名称/类型及截断标记。说明外发包含原上下文，最多追加一次调用，与初始调用共用 USD 0.05。勾选后按钮明确为“确认执行并回传结果”；未勾选仍走执行后预览确认，不继承其他轮次选择。API 新增严格 allow_result_model=false，拒绝动作不能同时批准回传。

Core 在创建任务前持久保存字段范围、原建议摘要、策略/资源范围、同意时间及五分钟期限；只有任务和聊天关联的事务提交后，才进入 waiting。重复确认须保持同一回传选择，不能修改已创建任务的同意方式。失败创建不派发，残留同意不触发模型；没有任务关联时不等待或外发。原执行授权和目录审批不变。

从 waiting 到最终回答期间保持同一轮活动，不接受新的会话消息，避免把尚未获得结果的旧说明送入连续追问。Core 在工具确实 succeeded/known、结果通过原验证器后，将有限结果转换为现有预览快照，重查当前权限、范围、摘要和期限，再进入原第二阶段队列。继续使用真实原生函数 ID、原上下文、8 KiB 结果及 32 KiB HTTP 上限；最终交换不提供工具。每日 USD 1/100 次、每轮最多两次和同根预算不变，没有第三次重试。

暂停阻止后续模型调用；归档、过期、权限变化、工具失败或未知结果阻止回传。用户可“停止自动回传”，仅撤回尚未启动的结果外发；取消工具仍通过任务卡。取消所有同时撤销等待回传并使用原工具取消协议。重启能继续尚未外发、仍有效的等待，但不会重复工具执行、初始调用或已经开始的第二次调用；中断成本仍保留未知预留。

迁移 010 只增加逐次同意和自动状态两列，扩展单会话活动唯一索引；旧记录默认无同意，不自动补发。沿用现有结果验证、预算、模型队列、停止和恢复代码。未回传的旧卡始终解释真实状态；已有后续消息时保留禁用的入口和原因，不隐藏卡片或自动将旧结果外发。模型也不能根据旧建议推断当前执行/审批状态。

本次功能选择不自动批准新生产停机、迁移 010 或新增真实验收调用。固定安装包检查完成后，用户另行明确批准 847f326 上线及最多三次真实验收；迁移、系统自动回答和连续追问已完成。该部署批准不包含额外重启，自扩展仍未实施。
