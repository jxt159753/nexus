# ADR 0012：获准工具结果与最终回答

日期：2026-10-19。状态：已批准实现；部署与实测状态见 [ROADMAP](../ROADMAP.md#12-m3-补充工具结果回传与最终回答)。取代 ADR 0011 中聊天每轮只调用一次、结果不回传的对应限制；其他边界保留。

用户要求“把获准的工具结果回传模型，再生成最终回答”。工具执行批准不等于外发批准：成功后提供具体任务的字段选择和实际内容预览，点击明确标明 DeepSeek 外发含义的按钮后，才排队生成最终回答。普通聊天仍一次；工具聊天最多两次交换，没有循环、自动重试或额外工具。沿用每天 USD 1、每日 100 次及每根轮次 USD 0.05，第二次只能预留首轮原额度减去已知费用的余额，不重置预算。

保留供应商真实的原生 tool_call ID、函数名和已校验参数。第二次发送原上下文、原 assistant 工具建议、匹配 ID 的 tool 消息；不伪造旧记录缺失的 ID。供应商格式见 [DeepSeek Tool Calls](https://api-docs.deepseek.com/guides/tool_calls/)。最终交换不提供工具，结果值始终按不受信数据处理，模型只能解读已有证据。后续普通聊天携带最终回答，不携带悬空工具调用。

仅允许本轮关联的 succeeded/known、node_report_schema_checked 结果，按原工具严格 schema 校验。系统白名单为系统名、版本、架构及 Python 版本；目录为工作区别名、直接条目名称/类型、截断状态，不发送文件内容、路径、身份、命令、凭证或原始错误。结果最多 8 KiB，超量目录裁剪并明确标记；用户可选字段，省略字段在包中注明。完整续接 messages 最多 28 KiB，超过时拒绝，不静默扩大原上下文。每次 HTTP 请求仍最多 32 KiB。

预览保存在 Core，摘要绑定原生调用、所选结果、源任务/修订、当前策略及范围、会话修订与五分钟期限；确认和开始调用前分别重查。仅最新空闲轮次可续接，新增消息或归档阻止旧确认；重复确认返回原状态。完成后的工具结果不受原执行期限影响，但当前身份、权限及新预览期限仍必须有效。

迁移 009 保留旧数据，新增 reply/summary 阶段、原回复、真实调用、结果快照及同意时间；model_calls 的唯一性从轮次改为轮次加阶段，严格最多两次。两阶段共用现有队列、全局并发锁、SSE、停止、全局取消及恢复逻辑；最终回答与工具成功分开显示，回答失败/停止/重启不重跑设备，缺最终用量继续保留余额预留。旧调用账本不改写，费用在轮次接口汇总。

本决策不批准生产停机、真实结果外发验收、新工具或自扩展。实现与验证完成后再形成具体生产升级请求，不能直接将新库交给旧版本或丢弃新增调用账本回退。
