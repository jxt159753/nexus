# ADR 0043：有界原文回取、记忆筛选与重复读取停滞

状态：2026-10-24 用户批准第一批后端实施，本地实现；验证与发布状态以 [P88](../ROADMAP.md#p88-context-efficiency) 为准。

## 背景与选择

参考 [dsh-agent-soul 固定版本](https://github.com/cyanwell/dsh-agent-soul/tree/544b0fb01bf6662f888857fffe4cf841a5a4276a) 中保留原文、摘要作为索引和确定性健康检查的思路。NEXUS 已有持久聊天、压缩来源、工具证据、自动记忆及调用预算，直接复用。没有移植常驻 SELF、逐轮记忆模型调用、自动重试插件或第二个记忆库。

## 决定

1. 压缩摘要携带 `ctx:<call_id 的 32 位十六进制>`，大型工具消息携带 `res:<step_id 的 32 位十六进制>`。完整来源列表、原文、验证状态和摘要仍保留在原表；只改变模型投影。旧压缩记录可直接生成引用，无迁移。
2. Core 工作目录增加 `context_read(reference, offset=0, query="")`。offset 是 Unicode 字符位置，query 为最多 120 字的字面定位文本；整页 JSON 最多 2 KiB、700 本地估算 token，返回 `next_offset`。检索是一次普通原生工作动作，消耗原动作／操作额度及后续正常模型交换预算，不额外安排模型、自动分页或摘要。模型只有在获得工作工具及结果外发授权时才能调用。
3. `ctx` 只读取当前轮次上下文来源集合中的同 owner、同会话原文，逐条重验完成状态、私有资料边界、自动记忆版本／有效期和来源摘要。`res` 只读取本轮先前已结算步骤，不重跑文件、网络或设备操作；图片不以 base64 文本回灌。归档、越界、来源改变或同意失效即拒绝。引用自身不授予权限。
4. 自动记忆在原 owner／项目／有效期过滤之后，按词片段稀有程度及长度归一排序。通用沟通偏好可无词匹配保留最多两条，兴趣等主题偏好需匹配查询。按范围及 NFC、CRLF、首尾空白归一键去重，保留内部空白、大小写、标点、否定和数值；不做语义合并，不删除旧条目，也不复活撤销记录。被手动选定的相同内容不重复注入。
5. 完整记忆引用仍保存在轮次记录和接口；模型只接收内容、类型、来源、验证、时间及必要的范围／有效期。最多 8 条、原引用总量 4 KiB，并新增整个记忆消息 800 估算 token 上限。当前用户纠正优先。分类和同义检索仍有局限。
6. 第四次相同只读动作派发前，若最近三个连续步骤的设备、参数和完整结果均相同，且没有新 steer，保存 `WORK_STALLED/not_started`，不执行该次读取。只覆盖文件读取／搜索、契约检查和原文回取；时间、在线状态、作业轮询、浏览器观察、Shell、写入和其他副作用不参与。不同参数、变化的结果、未知结果、中间的其他动作或纠正都会打断判定。整个批次均被此规则拒绝时结束工具循环，沿原失败说明通道在原预算内最多解释一次；混合批次保留其他动作。此信号只表示重复操作没有提供新信息，不证明目标完成或永远无法推进。

## 成本与兼容性

普通聊天没有新增固定说明或模型调用；工作目录增加一个工具契约。无新依赖、配置或 schema，客户端通过原目录取得工具摘要；既有本轮目录快照仍按旧契约执行。停止后的总结清空无用工具目录，不降低输出上限、不改变权限、原文存储、未知执行对账或原有调用上限。

短来源列表可能因新工具说明而净增 token；较长列表、重复／无关记忆及停滞循环才有明显收益。一次必要原文回取也会消耗动作和后续模型输入，不能承诺每轮都更省。量化结果使用完整请求正文及现有启发式估算器，见 [证据](../assets/context-efficiency-evidence.json)，不把本地结果当作真实供应商用量或任务质量验收。
