# ADR 0049：Android 无障碍操作与授权目录

日期：2026-10-26。状态：本项实现决定；部署与用户验收见 [P104](../ROADMAP.md#p104-android-control)。

## 背景

用户要求补齐手机 Node 的无障碍操作和文件读写，并允许本次由 Codex 实现必要界面。已有 Android 独立执行进程、会话登记、文件接收与持久回执可复用。

## 决定

采用系统 AccessibilityService 的语义节点动作及 SAF 用户选择目录，不引入 root、ADB 常驻、全盘权限或手机端规划器。服务位于已有 `:node` 进程，只在认证命令到达后读取一次界面或执行一个动作；审批绑定摘要，操作后有独立观察证据。Core 与本地、系统权限保持交集，新能力默认关闭。

真机反馈后的导航修正：主页与最近任务不指向界面控件，整页文字变化不应使其失效。0.1.13 起在服务内存中仅保留最近观察的摘要、前台包名、窗口编号和单调时间；这两项动作核对该引用、同一应用／窗口及两分钟有效期。返回和控件动作继续严格核对当前整页摘要；未知／过期引用或窗口变化仍拒绝。该缓存不持久化界面内容，不增加后台采集、自动重试或权限。

复用现有文件预览任务和写入绑定；SAF URI 不越过手机边界。写入使用同目录暂存、旧文件改名备份及实际读回。提供方无事务，因此中途故障保留 unknown 和恢复文件，不通过自动重试掩盖不确定效果。限于有界 UTF-8 文本、已有父目录和支持重命名的提供方。

迁移042仅扩展原授权表的工具／资源约束并保留原行。Node hello 资源根容量由3调整为5，以同时容纳设备状态、通知、收件箱、界面和授权目录。不新增依赖、任务状态机或后台数据采集。

本机开关复用加密 Vault，但读写都经过同一进程内锁及跨进程文件锁，保存后读回确认。Android AtomicFile 本身不提供并发保护；模拟器中曾观察到 Node 读取删除 UI 正在写入的 `.new` 文件，因此不能仅靠每个 Vault 实例的 `@Synchronized`。

用户随后明确允许把按需手机截图发送给现有 DeepSeek，用于识别与操作。0.1.14 复用 AccessibilityService 的截图与手势接口，新增独立 `vision` 权限及本机开关，不引入第二个模型循环。Core 将已核验的截图作为图片输入，保留最近四幅模型输入，完整任务／回执证据不裁掉。Node 缓存最近原图两分钟；手势绑定窗口、方向及目标区域像素，允许无关区域刷新。坐标按实际返回图片尺寸及裁剪区域映射；提交后失败保留 unknown，不能自动重试。

迁移043仅为两项屏幕工具扩展原授权约束，原行保持，新权限默认关闭。截图有界压缩，支持局部裁剪以改善细字识别；密码控件遮盖、锁屏／安全窗口拒绝及本App／系统授权页面禁止坐标操作继续生效。Android 11 以下仍可使用原语义控件与文件功能。

## 取舍

语义节点更便于绑定操作对象和复查结果；无可读节点的自绘控件由显式启用的截图视觉通道补充。SAF 可由用户准确授予目录，兼容 Android 沙箱；不承诺其他 App 私有数据或所有文档提供方的写入能力。输入／点击返回只证明动作返回，文件读回只证明该提供方当前返回的字节；均不提升为完整业务目标验收。

接口与使用见[手机操作与文件](../android-node-control.md)，真机红魔兼容、后台保活与最终用户验收另行记录。
