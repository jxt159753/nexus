# ADR 0018：会话范围内的有限工作权限

后续默认文件策略、多工具交换和网页工具由 [ADR 0019](0019-workspace-defaults-web-tools.md) 替代相关部分；本文件保留原发布设计与旧显式授权语义。

日期：2026-10-20。用户追加要求新工具与 Skill 能在聊天工作中自行调用、减少繁琐确认、用自然语言请求权限，并增加节点状态工具；完成后部署及上传 GitHub。

沿用已经明确选择的“指定工作区＋写入审批＋受控命令”。会话工作由用户一次开启，绑定会话、owner、设备、资源摘要和策略版本，最长 30 分钟、最多 20 次底层操作，可随时撤销。默认可自动查询状态、读取/查找、运行已批准启用的固定 Tool/Skill 与固定命令；可选择命令也逐次确认。文件写入始终先运行真实预览，再显示差异，用“同意 / 不同意”等明确自然语言答复批准当前步骤。模糊答复不调用模型判断权限；修改内容需新请求。

每轮发送单独同意外发目录和实际结果，包括本次读取正文与命令输出。执行授权不代替模型外发同意，也不代替长期记忆保存/引用同意。旧会话没有自动新增授权。已完成工作结果及其回答不自动带入后续普通聊天，避免旧外发同意隐式延续。

一次用户请求最多 4 个原生函数动作、5 次模型交换，共用原每轮 USD 0.05、每日 USD 1、每日 100 次和全局单并发。每次调用先落盘及预留余额，未知费用禁止续接。达到上限后不给模型工具。执行未知时停止工作，不让模型另建动作重跑。

Core 仅协调动作及上下文；TaskRepository/Harness、SkillService 和 ToolService 继续负责原始持久执行。每次新任务先原子关联工作步骤并消耗操作额度，再检查原身份/工具/资源交集。自动审批仍保存绑定具体任务、版本、参数、范围、策略和期限的原审批记录；每次派发重查会话授权。撤销、归档、取消所有、策略或资源变化和期限失效均阻止后续动作。停止工作同时请求取消真实子任务/流程；未知的沙箱仍沿用原日志对账。重启不自动续发模型或重做动作。

`get_node_status` 由 Core 查询当前认证连接、心跳年龄、在线与忙闲和有效能力；离线也能返回观测。输出标注 `core_connection_observation` 与观测时间，不宣称是 CPU、内存、电量或硬件健康采样。心跳和状态查询本身不调用模型。

迁移 016 新增会话授权、动作关联、自然语言答复及操作计数；扩展原调用账本的工作根轮次/序号，保留旧两阶段唯一约束与旧字段。升级前一致备份并逐表比较旧字段。Tool/Skill 新版本仍需独立批准，不因工作授权自动生成或启用版本。
