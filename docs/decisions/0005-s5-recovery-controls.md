# ADR 0005：有界对账、停止证据与持久控制

日期：2026-10-18。范围：用户“完成S5”批准的 S5/P08。状态：已实施，技术验证见 [S5 记录](../S5-VERIFICATION.md)，用户验收见 [ROADMAP](../ROADMAP.md)。

沿用单活 Core、单步只读工具和每 Node 单槽。以原 attempt 恢复，不增加中间件或第二状态中心。重连和丢确认先查询，received/not_found 重传原命令；明确失败或旧进程已停止但结果未知时，才允许最多第二次只读执行。每次继续检查当前授权及审批。

任务终态与 execution_outcome 分离：超时先确定，实际执行仍可未知；迟到证据不改终态，旧尝试不覆盖新尝试。每 attempt 最多三次派发、64 次状态/停止请求；额度用尽仍未知则保留槽，避免无限控制消息或未经确认的并行执行。

持久 pause 和幂等 owner 控制请求。暂停/取消与实际发送互斥，发送端重查授权，覆盖已排队但尚未发送的窗口。cancel_all 原子处理当前任务快照，不暗含暂停。

Node 取消先写墓碑，防止旧命令迟到启动，再停止真实 Windows Job。status_result 的可选 execution_stopped 缺省 false，不根据 boot_id 改变推断未执行。严格 v1 Core/Node 同批升级；动作摘要不变。Node 模式升级增加一致备份；回执和墓碑均不自动删除。

S5 以现有 owner HTTP 暴露控制，前端和长期记忆留在 S6。零真实模型调用，无新依赖。接口与限制见 [恢复说明](../s5-recovery.md)。
