# ADR 0010：先实现多轮自由聊天，沿用唯一 Core 和统一费用账本

日期：2026-10-18。状态：用户已批准首版实现范围；部署与验收以 [ROADMAP](../ROADMAP.md#10-自由聊天优先与-m3)为准。

## 背景

M2 只把单句文本解释成已有动作，没有普通回答或会话上下文。用户要求先自由聊天，再实现 Tool/Skill 自扩展，并批准 DeepSeek 多轮聊天、历史、停止及当前会话近期消息外发。

## 决定

- Core 新增持久会话和轮次，角色与上下文由服务端构造。Provider 使用单次 SSE 交换，浏览器从已持久快照读取真实增量；不新增独立大脑、消息服务或运行依赖。
- chat_enabled 默认 false，聊天输出上限独立于 M2 的 512 token。每轮最多一次模型调用；与 M2 共用全局单并发和 UTC 预算，未知费用跨日保留。
- 用户逐次发送即确认界面明确说明的外发范围，可只发送当前文字。最多最近 10 轮且有字节上限，不为摘要、标题或自动续写追加模型调用，不自动外发记忆或工具结果。
- 停止关闭实际 HTTP，断流和重启不自动重发。部分回答、实际结束状态与费用账本分别保存；会话归档不删除审计历史。
- 首版纯聊天不调用设备工具。保留已有任务视图；聊天中的模型工具建议和自扩展均不由本次范围自动授权。

## 影响

迁移 007 无损增加数据结构，升级需一致备份。历史有配额且无自动删除；长对话可能裁剪较早上下文，界面明确提示。流式用量缺失时完整保留预留，可能较早耗尽日额度。具体约束和使用方式见 [M3 说明](../m3-chat.md)。
