# ADR 0039：持续同意下的自动长期记忆

日期：2026-10-23。状态：按用户明确选择采用；实现及发布状态见 [P79](../ROADMAP.md#p79-auto-memory)。

用户要求自动创建并使用长期记忆，随后明确同意：仅从开启后的对话记住明确偏好、个人背景和持续事项；个人跨会话、项目同项目，排除秘密；允许后续相关对话自动发送给当前模型，保留查看、纠正、撤销和关闭能力。这份持续授权替代该范围内的逐条保存和逐轮外发确认，不涉及历史回填、其他owner或前端实施。之后用户独立明确批准性格与自动记忆共同部署、开启及真实模型验证，状态以P79为准。

复用 Core 的 SQLite 记忆库、聊天 Provider、预算、调用审计和事务。模型被要求在正常回复开头输出有界元数据；真实模型曾拆行或后置，因此 Provider 按保留标记隔离最多 4 KiB 的严格 JSON，不依赖其具体位置或分片方式。最多 3 条当前用户原文摘录，Core 校验后保存为未验证的事实或计划。压缩与仅解释的收尾不抽取记忆。不新增模型调用、向量库、Node 记忆或独立认知循环；这避免为每句话增加第二次调用及另一套取消/结算状态机。

保存与外发的持续同意由 owner 控制 API 一次记录；旧库默认关闭。每轮绑定当前策略版本与自动引用，关闭或更改记忆会使旧自动上下文失效，最早有效期沿普通/压缩历史传递。启动模型前和记忆提交时复核，避免旧排队任务继续使用已经撤销的同意。原手动记忆和资料引用仍保留原有独立边界。历史与已发数据不物理删除、不伪称可以撤回。

取舍：使用原文降低无依据改写，语义分类仍可能出错；有界词片段检索可能漏掉同义表达，秘密规则也不是通用识别证明。提供来源、未验证标记和可纠正记录，不把模型自述视为落盘证据。接口、容量和 DSH 接入详见[自动记忆](../automatic-memory.md)。
