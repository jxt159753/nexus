# ADR 0033：工具参数拒绝的有界反馈与诊断

日期：2026-10-23。状态：已采纳；属于 P64 网页生成失败修复，验证、部署与用户验收统一记 [ROADMAP](../ROADMAP.md)。

09:10 用户再次报告网页生成返回 `MODEL_RESPONSE_INVALID`。线上只读记录确认该轮请求上限为 256000，失败交换实际输出 4223 token，因此不是先前的 2048 截断。此前已完成两项文件查询，没有产生写入任务；失败交换的旧 `response_json` 为空，无法追溯其具体参数、终止原因或校验字段，不将某个推测写成该轮已确认根因。

检查发现可独立复现的问题：`write_file.content` 的 JSON Schema `maxLength=12000` 按字符计数，实际文件工具还限制 UTF-8 正文不超过 12000 字节。4001 个汉字符合字符数但达到 12003 字节；旧 Provider 将该严格校验错误归为整轮 `MODEL_RESPONSE_INVALID`，不返回可修正的工具证据。

## 决定

1. 保留文件、参数、请求、路径、预览与旧内容绑定限制。在工具描述和系统提示中明确字节与字符的区别，提示精简或在剩余动作内拆文件。
2. 完整且有效的 `tool_calls` 信封、有效用量、当前已提供的函数，若其参数 JSON 或严格契约校验失败，拒绝整个批次；不执行其中其他合法调用，不创建执行任务。
3. 保留原生调用与失败证据，在 owner 的交换日志记录失败；向下一次模型交换返回 `execution_outcome=not_started`、`batch_executed=false`、字段/错误类型及适用的 UTF-8 实际字节与上限。诊断不包含异常正文、参数值、路径或密钥。原生调用参数仍只保存在已有受认证的交换记录中。
4. 已知的执行前参数拒绝可在原 4 动作/5 次模型交换内修正，消耗现有交换轮次，不重置计数、不扩大金额/次数/token/时限或工具权限。每次继续前仍检查费用、次数、身份、授权、上下文与停止状态。原轮次不足、取消、撤销或重启均不静默继续。
5. 未提供函数、非法/重复调用 ID、信封错误、未知用量、超时及 `length` 不进入此参数修正路径。保留既有停止语义；失败交换新增有界阶段、终止原因及数量诊断，不记录原始异常或远端响应正文。

无前端、Node、依赖或数据库迁移变更。不重写用户历史失败，不自动重放其网页请求。模拟流与临时文件的成功不能替代供应商实际输出或用户最终验收。
