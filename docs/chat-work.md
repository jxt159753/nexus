# 在聊天中完成有限工作

聊天里选择目标设备，新建或打开会话，展开“会话工作权限”。核对工作区及命令权限后点击“按上述范围授权当前会话”，可使用 30 分钟、最多 20 次底层操作。授权不改变设备配置的 workspace，也不能访问任意电脑目录。

启用“本轮使用会话授权”时，发送按钮明确同意将输入、所选上下文、可用能力目录和实际工具结果发送给 DeepSeek。读取的文件正文和固定命令输出也在范围内；敏感内容不应放在该授权工作区内。记忆仍走独立的保存/引用选择。

可直接提出“看看节点是否在线”“查找所有 txt 文件”“读取 notes.txt”“使用已启用的流程做工作区概览”。模型只能从当前有效目录中选择。目录中没有工具或流程时，先说明能力缺口；生成新版本仍从能力页审阅、测试和逐版批准。

写入时会先显示真实差异及具体文件。直接在输入框回复“同意”“可以”“确认执行”或“不同意”“取消”；该答复由 Core 固定规则检查，不产生额外模型调用。确认绑定当前内容及预览，刷新不会重新执行。若想改内容，停止本轮后重新提出请求。

固定命令仅允许管理员配置的程序与固定参数。会话授权可选择让固定命令直接执行，或每次先用聊天确认；任意命令字符串、参数或 shell 均不可用。

每轮最多 4 个动作、5 次模型交换，共用 USD 0.05；每日额度仍为 USD 1、100 次。工具或流程内的每次底层操作计入会话额度。已批准版本、设备范围和授权在派发前重查；结果未知、失效或超限会停止。工作记录保留实际任务和验证级别。

“停止本轮工作”会关闭模型交换并请求取消关联执行；“撤销会话授权并停止工作”还会禁止该授权的新请求。正在停止、已经结束和执行未知以原任务记录为准。暂停新派发使用原全局控制。

节点状态展示 Core 观察到的在线/离线、忙闲、心跳年龄、工具与资源别名及观测时间。离线时忙闲不可确定；此工具不提供 CPU、内存、传感器或系统负载采样。

接口：

- `GET /api/v1/chat/work-catalog?node_id=...`：权限过滤后的固定目录及摘要。
- `POST /api/v1/chat/conversations/{id}/work-grant`：明确同意的有界会话授权。
- `DELETE /api/v1/chat/conversations/{id}/work-grant`：撤销并停止相关工作。
- 原聊天提交增加 `work_grant_id`、`work_digest`、`allow_work_results`，仍需原外发同意和设备选择。
- `POST /api/v1/chat/turns/{id}/permission`：绑定步骤、轮次 revision、幂等请求号及自然语言答复。
