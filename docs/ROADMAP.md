## 1. 执行方式

- 每次先完整读取 AGENTS.md、ARCHITECTURE.md 和本文件，确认当前批准阶段，再按 P01–P12 的依赖顺序执行该范围内的任务。
- 依赖满足只是技术前提；跨阶段还必须获得明确批准，不一次生成整个项目。
- 每项提交可检查的改动、运行与范围相称的测试，并报告实际结果和限制。普通单元测试不能替代真实进程与设备验收。
- 架构或安全边界发生实质改变时先更新设计并获得确认；普通实现细节自主决定。
- 只操作 NEXUS 工作区。测试文件均放临时目录；不扫描其他项目，不自动操作 Godot、系统设置或防火墙。
- 只有 S1/P01 获准后，才初始化 Git、建立工程与必要依赖；不自动推送远程仓库。

## 4. 真实端到端场景

主场景必须依次满足：

1. 在 Windows 分别启动 Core 和 Node，记录两个独立进程。
2. Node 使用自己的凭证连接；Core 显示节点在线且只拥有已授权能力。
3. Android 浏览器访问受信 HTTPS 页面并登录，建立同源 WSS。
4. 用户提交“读取系统信息”，Core 持久化任务并返回 accepted。
5. 规则路由命中，既有明确只读授权通过；Node 执行受限工具。
6. Core 验证工具证据并推送 succeeded；页面看到结构化结果与验证级别。
7. 用户提交“列出 workspace 目录”，任务停在 awaiting_approval；批准后执行。
8. 重复提交相同 request_id，返回相同任务；修改内容但复用该 ID 返回冲突。
9. 停止并重启 Core，重新登录后仍能查询原任务、结果、审批及执行历史。
10. 全程没有配置模型 API Key，没有外部模型请求，模型调用表不存在真实调用，路由记录明确为 rule。

## 5. 故障与边界验收矩阵

| 场景 | 预期行为 | 验证层级 |
| --- | --- | --- |
| 非法 JSON、未知类型/版本、消息超大 | 明确拒绝，不创建或执行任务 | 协议单元 + WS 集成 |
| 未登录浏览器、错误 Node 令牌、错角色消息 | 连接或操作被拒绝，无设备执行 | WS 集成 |
| 非允许 Origin、失效会话、撤销 Node 凭证 | 拒绝新操作并关闭相关旧连接 | 安全集成 |
| 任意路径、UNC、越界 root_id、junction 根 | 参数或资源校验失败；不访问未授权目标 | Windows 工具集成 |
| 目录条目是链接或恶意 HTML 文件名 | 不跟随目标；页面显示文本；明确截断 | 工具 + UI |
| 等待审批时改参数、换 Node、策略变化 | 原批准失效或动作不允许改变；重新评估 | 状态机 + 集成 |
| Core 在派发落盘后、网络发送前崩溃 | 重启恢复待派发尝试，无丢任务 | 独立进程故障注入 |
| Node 已接收但 command.accepted 丢失 | 使用同 attempt 查询/重传，无重复执行 | Link 集成 + 回执计数 |
| Node 执行后、Core 收结果前断线 | 本地结果落盘，重连后重传，Core 仅结算一次 | 独立进程/网络故障 |
| Core 结果落盘后、result.ack 前崩溃 | Node 可重传，Core 去重，历史仍一致 | 独立进程故障注入 |
| Node 在 started 与结果落盘之间崩溃 | 标记未知并先处理旧执行；不因进程重启假定未执行 | 进程与回执测试 |
| Node 父进程强制退出或工具进程无法纳管 | OS 清理已纳管工具进程；纳管失败时工具不运行；恢复不把已发生的读取当作未发生 | Windows Job Object 故障测试 |
| 工具超过期限或收到取消 | Node 确认终止实际执行；无法确认则记录未知，不假称停止 | 受控阻塞测试工具 |
| 取消/超时/成功竞争、旧 attempt 迟到 | 事务决定唯一终态；旧回执不覆盖新结果 | 状态机并发集成 |
| Core 重启且节点离线 | 保留任务；等待/对账至期限；不伪报成功或失败原因 | 独立进程测试 |
| 全局暂停、取消所有、暂停后重启 | 控制状态持久；暂停不新派发；取消有真实确认或未知标记 | 集成 |
| 重试、并发、队列与结果上限 | 所有限额被实际执行；不无限重试或堆积 | Harness 集成 |
| 数据库写入失败、Node 无法写回执 | 拒绝接受/继续派发或执行，不能无审计运行 | 存储故障注入 |
| 浏览器断线后重连、慢客户端 | 同步历史无丢任务；慢客户端不阻塞调度 | WS 集成 + 浏览器 |
| 模型路由被误请求 | 返回 MODEL_DISABLED，零 Provider 调用 | 路由 + 预算单元 |
| 从一致备份恢复 | 原历史、身份范围和审批记录保持可查询；重新确认 Node 在线 | 恢复演练 |
