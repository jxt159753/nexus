## 中间失败与纠正

- 受限 Windows 环境在 asyncio 的 socketpair 初始化停住，诊断栈定位后停止所属测试，使用获准的本地执行环境验证；不把该停顿归因于业务数据库损坏。
- 首轮 Windows 837 通过、5 失败、2 跳过，Linux 250 通过、5 失败；五项均为迁移测试仍期待 019。更新为 020 后完整回归与 Linux 检查通过，旧行、外键和一致备份断言仍保留。
- pip 在受限临时目录构建失败，改用已有 setuptools 后端构建，无依赖下载。
- 一次远程 Python 内联引号导致候选测试归档解包失败；改用固定脚本完成解包并重跑最终 259 项检查，未触及生产。
- 上传候选脚本曾因自动审批服务账号用量上限而未执行；用户要求继续后，审批恢复，原上传完成。没有绕过审核。
